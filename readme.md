# ACC Recursive Model Collapse

## Getting started

This repository contains the code for the ACC recursive model collapse project.

Run the starter application with:

```bash
python main.py
```

Install project dependencies, when listed, with:

```bash
python -m pip install -r requirements.txt
```

## Contributing

Make changes on a separate branch and open a pull request (PR) for review. Do not merge changes directly into `main`.

1. Start from an up-to-date `main` branch and create a descriptive branch:

	```bash
	git switch main
	git pull
	git switch -c feature/short-description
	```

2. Make and test your changes, then commit and push the branch:

	```bash
	git add .
	git commit -m "Describe the change"
	git push -u origin feature/short-description
	```

3. Open a PR from your branch into `main`. Request review, address feedback, and merge only after approval and required checks pass.
